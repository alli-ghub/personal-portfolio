- `project3.png` — Student Registration Form screenshot

## Run Locally
1. Download or clone the repository.
2. Keep `index.html`, `styles.css`, `script.js`, `project2.png`, and `project3.png` together in the same main folder.
3. Open `index.html` in a web browser.

## Add Your Profile Photo
1. Put your photo in the same folder as `index.html`.
2. Open `index.html` and find the comment marked `PROFILE PHOTO`.
3. Replace the profile placeholder `<div>` with this image element:

`<img class="profile-photo" src="your-photo.jpg" alt="Alliah Kelly H. Baldo">`

4. Replace `your-photo.jpg` with your image's exact filename.

## Note
The Student Registration Form uses PHP. GitHub Pages can host the static portfolio, but it does not run PHP server-side code. The full PHP form needs PHP-compatible hosting.
