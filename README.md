- Home / Introduction

- Skills
- My Projects

## Files
- `index.html` — website content and structure
- `styles.css` — lavender theme and responsive layout
- `script.js` — mobile navigation menu
- `profile.png` — supplied profile photo
- `project2.png` — screenshot for Live Message Preview Tool
- `project3.png` — screenshot for Student Registration Form

## How to View
Keep all files in the same folder, then open `index.html` in a web browser.

The two project screenshots should be placed in the main folder using these exact names:
- `project2.png`
- `project3.png`

The profile photo is already included as `profile.png`.
