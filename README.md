## Run the Website Locally
1. Download or clone this repository.
2. Keep `index.html`, `styles.css`, `script.js`, `project2.png`, and `project3.png` together in the same main folder.
3. Open `index.html` in a web browser.

## Add Your Profile Photo
Put your photo in the same folder as `index.html`. In `index.html`, find the comment `PROFILE PHOTO` and replace the placeholder `<div>` with an image element. Example:

`<img class="profile-photo" src="your-photo.jpg" alt="Alliah Kelly H. Baldo">`

Change `your-photo.jpg` to the exact filename of your image.

## Notes
The Student Registration Form uses PHP. GitHub Pages can host the portfolio's static files but does not execute PHP, so the PHP form's full live functionality needs PHP-compatible hosting.
