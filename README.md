# Alliah Kelly H. Baldo — Personal Portfolio

A simple personal portfolio made with HTML, CSS, and vanilla JavaScript.

## Files
- `index.html` — portfolio content and sections
- `styles.css` — layout, colors, and responsive styling
- `script.js` — mobile navigation and small page interactions
- `profile.png` — profile photo
- `project2.png` and `project3.png` — project screenshots

## Project section
Projects are arranged one after another. Each project preview is on the left and its details are on the right on wider screens. On smaller screens, the preview appears above the details. Screenshots keep their original proportions so the full image remains visible.

## How to view
Open `index.html` in a browser. No frameworks, build tools, or installation are needed.
